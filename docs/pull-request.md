The agency website needs a visual direction before production implementation. This change adds a review gallery and five complete, responsive HTML concepts: Signal, Prism, Vector, Orbit and Atlas. Each includes a compact sticky header, mobile navigation, anchor sections, switchable workflow examples, FAQs and a local enquiry preview.

The pages require no build step or external assets. Open `drafts/index.html` locally, or run `python3 -m http.server 8000 --directory drafts`. The hosting guide compares Hetzner and Vercel Pro and explains the stack and release-process changes involved in choosing Webflow.

Validation: HTML structure/links/anchors and JavaScript syntax checked; all five desktop compositions reviewed in Chromium; responsive overflow checked at 320, 390, 768 and 1280 px nominal frame widths; mobile navigation, workflow switching, FAQs and enquiry-preview results exercised. Physical-device, Safari/Firefox and full accessibility checks remain for the selected production implementation.

This is a design-review change. No hosting deployment, live lead capture, CRM connection or analytics is enabled. Agency naming is provisional and workflows are explicitly illustrative.
